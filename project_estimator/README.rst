Descripción
===========
Este módulo agrega una aplicación en el menú principal de aplicaciones.
Solo sirve para estimar horas y crear ventas en base a las estimaciones.
Se puede Calcular las horas por porcentajes, por etiquetas con horas preconfiguradas, o de forma manual.
El logo, título y subtítulo son personalizables.
